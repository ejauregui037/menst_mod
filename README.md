# menst_mod

Menstrual modeling: Collaboration with L. Houghton

Code contained applies SkipTrack to extract cycle irregularity statistics (tau_i, cycle variance), generate 'corrected' cycle lengths (with c_ij), & estimate individual mean cycle lengths (from median estimated in SkipTrack; from c_ij-corrected cycle lengths; from raw cycle lengths) 

Repo also contains explored analyses for potential predictors in SkipTrack model (deprecated -- no effect on SkipTrack results, likely related to insufficient sample size and/or covariate variation) & lmtp code.

**This directory is the root directory for this git repo. All scripts in this repo will set this directory, `menst_mod/`, to the working directory, and all filepaths will be relative to this root (e.g. `./data`).

* `data/` : Data files for project. Documentation included. Files are not pushed to git, just stored locally. *osf.io?*
