# fitting/

> Scripts to fit skipTrack to Clue data

>> Note that there are no scripts in here testing whether adding birth control as a covariate is informative; in previous iterations of the project, we tested that and found that adding birth control did not affect $\tau_i$ estimates (hardly affected, even to many decimal places, for most individuals.) Furthermore, MCMC fit diagnostics were much worse. Therefore, those scripts are left in `fitting/deprecated/`
